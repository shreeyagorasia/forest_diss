## TEMP holding note — does RQ2a's own residual-reduction value cluster spatially? (2026-08-16)

**Context**: during figure planning, a spatial "help map" for RQ2a (where does environmental
conditioning help or hurt) was explicitly NOT proposed, because no supporting spatial-clustering
statistic existed yet for the reduction values themselves — only for raw residuals, computed
separately for RQ2b/RQ3. This closes that gap.

**Method**: `models/spatial_attribution/rq2a_reduction_morans_i.py`. No new fitting — composes three
already-existing pieces: `compute_residual_reduction()`
(`models/spatial_attribution/rq2_residual_reduction.py`, the exact function already behind RQ2a's
own quartile tables) for the per-row reduction value (`|CR error| - |model error|`);
`load_plot_coordinates()` (`models/common/geo.py`) for (x, y); `compute_residual_morans_i()`
(`models/growth_curve_attribution/residual_spatial_autocorrelation_check.py`, k=8 nearest-neighbour
weights, 999 permutations, seed=42 — the same function and convention already used for RQ2b's and
RQ3's own residual Moran's I) for the test itself. DNN and XGBoost (both env-conditioned, Set3,
seed 42/fixed config), both cohorts, pooled across all 5 `spatial_block_kfold` test folds.

### Results

| Cohort | Model | n | Moran's I | p |
|---|---|---:|---:|---:|
| 4survey | DNN | 232,292 | +0.6424 | 0.001 |
| 4survey | XGBoost | 232,292 | +0.6281 | 0.001 |
| 6survey | DNN | 82,614 | +0.5698 | 0.001 |
| 6survey | XGBoost | 82,614 | +0.5499 | 0.001 |

**The reduction value is substantially spatially clustered, for both models, on both cohorts** —
Moran's I 0.55–0.64, p at the permutation floor (0.001, the smallest value 999 permutations can
report) in every case. This is not a marginal or borderline result: it sits in the same range as
RQ2b's own residual Moran's I (0.65–0.74) and RQ3's (comparable magnitude), both already reported
as "substantial" spatial clustering elsewhere in this project. Where conditioning helps or hurts is
not scattered randomly across Aberfoyle — it is a real, strongly spatially-structured pattern, for
both models and both cohorts alike.

**What this does and doesn't establish**: this confirms the SIGN/MAGNITUDE of the reduction effect
clusters spatially — consistent with, though not a direct test of, the already-established
CR-residual-quartile mechanism (RQ2a item 1: conditioning helps where CR fits worst, hurts where it
fits well) is not scattered evenly across Aberfoyle. Whether the clustering is because "where CR
fits worst" is itself spatially clustered (a plausible, likely candidate — CR-quartile membership
was not itself tested for spatial clustering here) or reflects some other spatially-structured
factor is not distinguished by this check alone. No causal claim is made or supported.

**Implication for the plotting plan**: this now supports a genuine, evidence-based spatial "help
map" for RQ2a, on the same basis already used to justify RQ2b's and RQ3's own maps — the map would
show a real, tested spatial pattern, not an unsupported visual.
