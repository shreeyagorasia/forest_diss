### XGBoost's own version of this check (2026-08-14) — does the residual-shrinkage pattern require PINN specifically?

**Motivation**: the XGBoost hyperparameter correction (`TEMP_rq1_baseline_comparison_2026-08-11.tex`)
found a fairly-configured XGBoost beats DNN on raw RQ1 accuracy. Before leaning on "PINN's residual
shrinks the shared curve's error especially cleanly" as the remaining case for using PINN despite
losing the accuracy contest, this checks whether that shrinkage pattern is actually
DNN/PINN-specific or something a plain tree ensemble also does.

**New**: `models/spatial_attribution/rq2a_xgb_check.py` — fits TWO XGBoost arms per fold (Set3
env-conditioned, and a no-env control), both using the corrected fixed config (matching the RQ1/

**Honest finding — does NOT give a clean "point for PINN," and this is worth stating plainly
rather than spinning it**:

1. **XGBoost shows the same qualitative pattern DNN does** — monotonically increasing reduction by
   quartile, concentrated on the plots CR does worst on, and environment clearly helps (env-arm
   beats no-env arm on both cohorts, +0.375 mean reduction on 4survey, +0.121 on 6survey). This
   "residual shrinks most where the shared curve is worst" pattern is NOT unique to physics-
   informed neural networks — a plain tree ensemble given the same environmental features shows it
   too.
2. **XGBoost's average reduction is comparable to, or even slightly larger than, DNN's** (1.597 vs
   1.501 on 4survey; 0.361 vs 0.174 on 6survey) — not a weaker effect.
3. **The one real, evidence-backed difference is stability, not shrinkage quality.** XGBoost's
   fold-to-fold SD is 5-14x larger than DNN's (0.330 vs 0.023 on 4survey; 0.183 vs 0.036 on
   6survey) — DNN's environmental-conditioning effect is a tight, highly reproducible pattern
   across different data folds; XGBoost shows a similar-sized average effect but far noisier
   fold-to-fold, consistent with tree ensembles' well-known higher variance relative to neural
   nets on this kind of tabular regression.

despite losing RQ1's raw-accuracy contest to XGBoost should NOT rest on "PINN's residual shrinks
the CR curve's error more cleanly" — that claim is not supported by this check. ~~It should rest on

### CORRECTION (2026-08-16) — the "XGBoost is 5-14x less stable" claim used mismatched SD types

**Caught during a document audit**: the "Honest finding" point 3 above compares XGBoost's
fold-to-fold SD (0.330/0.183, from the single-seed 5-fold run in the table just above) against
DNN's row labelled "(env-conditioned, existing) | 1.501±0.023 | 0.174±0.036" — but those DNN
numbers are the **5-SEED reseed SD** (seed-to-seed variability of the fold-pooled mean, Step 4a
above), not DNN's own fold-to-fold SD. These are different quantities (training-randomness
stability vs. spatial-split sensitivity) and are not comparable in magnitude by construction —
seed-to-seed SD is expected to be much smaller than fold-to-fold SD for almost any model, since
changing the held-out spatial region changes the actual data being evaluated, while changing the
training seed only changes weight initialisation on the same data.

**The correct like-for-like comparison** uses DNN's OWN single-seed fold-to-fold SD, already in
the "Results — overall" table above: Set3 4survey = 1.495±**0.386**, Set3 6survey =
0.190±**0.264**. Compared against XGBoost's fold SD (0.330/0.183):

| Cohort | DNN fold-to-fold SD | XGBoost fold-to-fold SD | XGBoost/DNN ratio |
|---|---:|---:|---:|
| 4survey | 0.386 | 0.330 | 0.85 |
| 6survey | 0.264 | 0.183 | 0.69 |

**XGBoost's fold-to-fold SD is actually SMALLER than DNN's on both cohorts** (85% and 69% of DNN's
own fold SD) — the opposite conclusion from "5-14x less stable." No new fitting was needed for this
correction — both numbers already existed in this same file, just never compared against each
other correctly. **The "far less fold-to-fold reproducibility" claim for XGBoost should be
retracted**; on the one basis that's actually comparable, XGBoost and DNN's fold-to-fold stability
are similar, if anything favouring XGBoost slightly. DNN's 5-seed reseed SD (0.023/0.036) remains a
real, separately-useful number — it just answers a different question ("does retraining with a new
seed change the answer," not "does XGBoost swing around more than DNN fold-to-fold") — and there is
no equivalent multi-seed reseed for XGBoost to compare it against directly.

**Scope note**: this was run on Set3 only (the same set used throughout the RQ1/DNN headline
comparisons, for direct comparability) plus a no-env control — Set2/Set4 were not tested for this
specific check.

### Testing the "Q1=noise, Q4=signal" mechanism against the 5-seed quartile data (2026-08-16)

**Motivation**: item 1's proposed mechanism (env conditioning hurts Q1 because there's little real
residual left to fit, so the model fits training noise there; helps Q4 because the large residual
is real, environment-linked signal) had never been directly tested — only asserted as plausible.
A cheap, no-retraining test: if Q1's harm really is "fitting noise," it should behave more
erratically across independent training runs (different random seeds) than Q4's help, which
should be a reproducible, systematic signal. The already-computed 5-seed reduction-by-quartile
table above (DNN, Set3, both cohorts) gives exactly this: compute each quartile's coefficient of
variation (CV = |SD / mean| across the 5 seeds) as a proxy for "is this effect systematic
(low CV) or erratic (high CV)."

| Cohort | Q1 CV | Q2 CV | Q3 CV | Q4 CV |
|---|---:|---:|---:|---:|
| 4survey | 3.3% | 8.8% | 1.6% | 2.3% |
| 6survey | 8.3% | 17.9% | 10.3% | 4.5% |

**Result: mixed, not a clean confirmation.** Q4 IS the most reproducible quartile on 4survey (2.3%,
second-lowest only to Q3's 1.6%) and clearly the most reproducible on 6survey (4.5%, lowest of all
four) — consistent with "Q4's help is real, systematic signal." But **Q1 is not the noisiest
quartile in either cohort — Q2 is** (8.8% vs Q1's 3.3% on 4survey; 17.9% vs Q1's 8.3% on 6survey).
This is more likely a denominator artifact than evidence against the mechanism: Q2's mean reduction
is close to zero (0.260m on 4survey, -0.319m on 6survey), so its CV is inflated by dividing by a
small number, not necessarily by more erratic underlying behaviour. Q1's own mean (-1.583m/
-1.093m) is large enough that its CV is a more trustworthy reproducibility signal, and it IS low
(single digits) — but "low" doesn't distinguish "genuinely reproducible harm" from "genuinely
reproducible noise-fitting," since both would look equally stable across seeds if the SAME noise
pattern in the training data gets fit the same way each time (seeds change model initialisation,
not the training data's noise itself).

**Conclusion**: this check does not cleanly prove or disprove the signal-vs-noise mechanism — it
confirms Q4's effect is highly reproducible (supporting "real signal" there) but the CV comparison
cannot actually distinguish "reproducible harm from noise-fitting" from "reproducible harm from a
real but undesirable systematic effect" at Q1, since seed-to-seed stability alone doesn't test
what's being fit, only whether the same thing is fit each time. A real test of the noise-vs-signal
claim specifically would need to look at whether Q1's residual correlates with anything
environment-linked at all (if it doesn't, "noise" is more supportable) or is itself systematic
across independent data subsets — not yet done, remains future work.
