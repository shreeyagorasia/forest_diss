\chapter{Data}
\label{ch:data}

\section{Study area}

Aberfoyle Forest lies within Queen Elizabeth Forest Park, Trossachs National Park, Stirlingshire, Scotland, centred roughly on OS National Grid reference NN~520~010. The forest extent is approximately 20\,km by 15\,km, with a non-uniform plot distribution clustered by management compartment. Elevation ranges from around 25\,m at the valley floor to over 500\,m on the ridges; terrain is characterised by steep-sided glens, exposed ridges, and lochs, consistent with the Highland Boundary Fault geology and glacially scoured valleys in this area. The exact plot or grid-cell size is not yet confirmed from Forest Research metadata; the current analysis treats records as spatial polygons or centroids in the OSGB36 coordinate system.

\section{LiDAR-derived plot data}
\label{sec:data-lidar}

Plot-level forest attributes are derived from airborne LiDAR surveys at six timestamps: 2002, 2006, 2008, 2012, 2021, and 2023. The acquisition platform is not confirmed in the metadata available at the time of writing, so this dissertation describes the data as airborne LiDAR-derived plot attributes rather than assuming a specific platform (for example, drone or fixed-wing).

Two related local data sources exist and should not be confused. A legacy CSV export (\texttt{LiDAR\_Years\_All\_attributes.csv}, dated 29 June) contains 1,152,801 rows and 23 columns. The current working source is a GeoPackage (\texttt{LiDAR\_Years\_All\_7jul.gpkg}) with two layers: \texttt{LiDAR\_Years}, containing 795,645 rows across 40 fields plus geometry, and \texttt{LiDAR\_Years\_SS}, a Sitka-spruce-filtered subset containing 376,080 rows. All modelling cohorts described below are derived from the GeoPackage, not the legacy CSV.

The main response variable is \texttt{Top\_Height95}, defined as \texttt{elev\_percentile\_95th} multiplied by 1.1. A related field, \texttt{Top\_Height99}, is derived from the 99th elevation percentile without a multiplier; because of how the two fields are constructed, \texttt{Top\_Height99} is lower than \texttt{Top\_Height95} in a substantial share of rows. This dissertation treats \texttt{Top\_Height95} as the primary response and \texttt{Top\_Height99} as an audit variable only.

\section{Cleaning decisions}

The cleaning logic is applied at plot level, after restricting to a required set of cohort years: a plot is kept only if it passes every rule in every required survey year, so the retained dataset stays balanced across timestamps. The rules are: keep the required cohort years; keep plots present in every required year; filter to Sitka spruce using \texttt{spis == "SS"}, since \texttt{spis} is the Forest Research inventory species code and disagrees systematically with the separate \texttt{Species} lookup field; keep valid planting years; keep plausible age, where \texttt{Age = LiDAR\_year - plyr}; and keep plausible \texttt{Top\_Height95} values. Volume is not used as a general cleaning rule -- negative \texttt{Vol\_RM95} values remain in the master export and are filtered only in volume-specific analyses, since volume is not part of the height modelling pipeline.

\section{Cleaned cohorts}

Two balanced Sitka spruce cohorts result from this cleaning logic. The four-survey cohort covers 2008, 2012, 2021, and 2023, and contains 71,766 plots (287,064 rows). The six-survey cohort covers all six years (2002, 2006, 2008, 2012, 2021, 2023) and contains 13,897 plots (83,382 rows). The four-survey cohort is the main dataset for spatial attribution because it is roughly five times larger; the six-survey cohort is used for full-span sensitivity checks and for the secondary temporal question, since only it covers the full 21-year range.

\section{Response variable and Chapman-Richards residuals}

The response variable for the growth model is \texttt{Top\_Height95}. Chapman-Richards parameters ($y_{\max}$, $k$, $p$) are optimised from the cleaned dataset by least squares, using \texttt{Age} as the biological time input, applied once across all plot-timestamp pairs. The residual for plot $i$ at time $t$ is
\[
\varepsilon_{i,t} = y_{i,t}^{\text{obs}} - y_{\text{CR}}(t_i \mid y_{\max}, k, p),
\]
where a positive residual means the plot is taller than the age-matched CR baseline predicts, and a negative residual means it is shorter. These parameters have not yet been fitted on the current cleaned cohorts at the time of writing this draft; Chapter~\ref{ch:results} reports placeholders pending that fit.

\section{Terrain and wind data sources}

Static terrain variables -- elevation, slope, northness, eastness, the Topographic Wetness Index (TWI), and TOPEX -- are planned for extraction from the OS Terrain 50 digital terrain model \citep{osdatahub2026OSTerrain50} (50\,m post spacing) at each plot centroid, using \texttt{rasterio} and \texttt{geopandas}. WASP wind exposure data will be added if it becomes available with a documented resolution, via the project contact at Forest Research. If WASP is unavailable or its resolution cannot be confirmed, the Global Wind Atlas \citep{globalwindatlas2026GlobalWindAtlas} (250\,m output grid) will be used as a public wind-climatology fallback, using the lowest above-ground height layer relevant to canopy-level exposure rather than a turbine-hub-height layer. None of these terrain or wind extractions have been run yet; Chapter~\ref{ch:results} reports this as outstanding work.

\section{Climate and soil data}

HadUK-Grid \citep{hollis2019HadUKGridGriddedClimate} provides 1\,km gridded daily UK climate observations and is the intended source for interval-level climate indices (for example, summer soil moisture deficit and growing degree days) computed once per inter-survey interval and applied to all plots within that interval. At 1\,km resolution, HadUK-Grid is coarse relative to the plot scale, so it is used here for temporal indices rather than as a plot-level spatial predictor unless extraction shows genuine within-forest variation. Soil data sources are treated the same way: they are candidates only if, after extraction to plot centroids, they show enough unique values inside Aberfoyle to distinguish nearby plots. Neither soil nor spatial climate extraction has been carried out at the time of writing.

\section{Leakage risks and excluded variables}
\label{sec:data-leakage}

Several fields in the GeoPackage are derived from height, age, or both, and would leak the target if used as predictors of \texttt{Top\_Height95}. These are excluded from all top-height predictor sets: \texttt{Vol95}, \texttt{Vol99}, \texttt{Vol\_RM95} (derived from height, area, and canopy cover), \texttt{GYCspec95} and \texttt{GYCspec99} (derived from height and age via a Chapman-Richards-style formula, and containing infinite or extreme values in places), raw height percentiles (\texttt{elev\_percentile\_95th}, \texttt{elev\_percentile\_99th}), and \texttt{Top\_Height99}.

The field \texttt{whcl} is a Forest Research inventory windthrow hazard class. It is not a raw wind measurement and appears to be linked to management decisions -- for example, plots with \texttt{whcl > 4} are thinned in only 2.63\% of records, concentrated in 312 distinct plots, and windthrow class 6 is almost entirely unthinned. \texttt{whcl} is retained for audit and stratification but excluded from baseline environmental predictor sets.

Management fields (\texttt{Thin}, \texttt{last\_thinn}, \texttt{time\_since\_thinning}) are useful as contextual covariates and as confounder flags, but they are not a substitute for terrain and wind attribution, since \texttt{Thin} only records whether a last-thinning year exists, not whether recent thinning affected the observed growth interval. Thinning remains the primary unobserved confounder discussed further in Chapter~\ref{ch:discussion}.

\section{Multicollinearity}

A correlation matrix and variance inflation factor (VIF) analysis are planned to identify collinear variable groups before modelling -- for example, elevation, TOPEX, and any wind exposure layer are all expected to capture overlapping aspects of exposure. Figure~\ref{fig:correlation-example} shows a Spearman correlation matrix computed on an earlier version of the cleaned cohorts, before the current terrain and wind features were joined; it is included to show the intended format of this check, not the correlation structure that will be used for feature selection in the final analysis. XGBoost is expected to handle correlated predictors implicitly; any linear baseline will drop the more redundant variable in any pair with VIF greater than 10.
