\section{Q2: Spatial attribution}

Q1 showed that global models -- one formula for the whole forest -- leave real spatial clustering in their errors. Q2 asks a direct question: does letting a model change by location (GNNWR) pick up what these global models miss?

By raw score, yes. GNNWR beats both global models on every set (Table~\ref{tab:results-q2}). On Set4, GNNWR scores 0.294 [0.236, 0.347], Elastic Net scores 0.240 [0.192, 0.286], and XGBoost scores 0.250 [0.201, 0.295]. But the ranges overlap every time, so we cannot say for sure that GNNWR is really better. Even its best score (0.320, on Set2) still leaves about two-thirds of the target unexplained.

So we asked a harder question: why does GNNWR win at all, even by this small, unsure amount? The answer changes the whole story.

\textbf{GNNWR's whole edge comes from one thing: CanopyCover. It is not a sign that GNNWR understands the environment better by place.} To test this, we took CanopyCover out and ran all three models again (Table~\ref{tab:results-q2-ablation}). Every model dropped to almost zero: Elastic Net 0.042, XGBoost 0.061, GNNWR 0.049. GNNWR gained nothing from being spatial once CanopyCover was gone. Then we ran all three models with CanopyCover alone, and nothing else. Every model climbed back to roughly the same share of its full score: Elastic Net 0.207 ($\sim$83\% of the gap), XGBoost 0.210 ($\sim$79\%), GNNWR 0.249 ($\sim$82\%). This is not a GNNWR quirk -- all three methods tell the same story. This is not just the target in disguise: CanopyCover's raw link to the target is a moderate 0.468, not close to 1. But it does mean the other 18 variables add almost nothing on their own. We tested GNNWR because we thought a model that can change by place would find hidden links between environment and growth. It did not. It simply found the one variable everyone already knew about, just expressed a little differently from place to place.

\textbf{Part of the reason so little else shows up is that Q2's own target is noisy.} The curve-fitting method keeps each plot's growth rate fixed to its yield class, and only fits the ceiling. If a plot's real growth rate does not match that assumption, the mismatch does not vanish -- it leaks into the ceiling number instead. Figure~\ref{fig:q2-example-plot} shows this on one real plot. Plot 309770's own fitted ceiling is 43.0m, well above its yield-class benchmark of 32.8m -- a gap of $+10.2$m. XGBoost predicts $+12.4$m for the same plot. The shaded area shows this gap over the years we actually measured, not just a guess at the far end. CanopyCover pulls this one prediction down, even though it usually pushes predictions up -- the direction is not fixed for every plot. A second plot (Appendix Figure~\ref{fig:q2-example-plot-typical}) shows this is not a cherry-picked case: it was picked because its error sits at the middle of the pack, and here the model only explains about half the gap, with no single variable standing out. This noisy target is why so little beyond CanopyCover comes through clearly.

\textbf{The same variables act the same way in Q1 and Q2 -- checked two different ways.} Table~\ref{tab:results-q2-reliability} lines up two separate tests. Q2's test: does GNNWR's own local number for a variable keep the same sign across compartments? Q1's test: does a plain Elastic Net model agree with a mixed-effects model on a variable's coefficient? CanopyCover, slope, and rainfall pass both tests -- they are reliable everywhere. Soil pH fails both -- it looks like noise in both chapters. Topex is the interesting one. In Q1, Elastic Net and the mixed-effects model disagree on it. But a closer check shows this is because topex carries a real, local effect (a within-compartment link of 0.214, stronger than its raw link of 0.080) that one straight line cannot capture well. This matches Q2's own finding: topex's local coefficient flips sign in more than a quarter of compartments (Figure~\ref{fig:q2-stability-map}). These are two different tests, not the same test twice -- that they agree makes the finding stronger, not weaker.

A few smaller points, stated briefly. Some terrain variables (windward\_topex, slope\_degrees) show a real curved link to the target -- rising, then flattening out. GNNWR can only draw straight lines, so it cannot fully use this signal even where it is real. The effect is small either way: CanopyCover already carries 80--90\% of the model's power. A small group of plots (under 1\% of the 4-survey cohort, 266 of 56,526) show an extreme version of the same rate-and-ceiling mixing described above. This is the tail of the main finding, not a separate one, so it is not covered in depth here (full diagnostics are preserved for Appendix~\ref{app:flagged-plot-split}). As planned, we also ran all three models on the six-survey cohort as a check, not as the main test. None found any real signal ($R^2\approx0$ for all three), which lines up with its much smaller number of compartments (47 vs.\ 231). We did not dig into this further, since six-survey was never the main focus.

\subsection*{Conclusion}
Q2 gives a real, useful negative result. Spatial modelling did not find hidden environmental drivers here. It just found the one variable every method already knew about. But now we know why it could not go further: the target itself blends two different kinds of error into one number, and GNNWR can only draw a straight line per place. This tells us the limit of this approach, not that place does not matter at all.
